## 3. 验收状态的含义

| 状态 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 内容已写 / 候选已交 | 文件、任务和规则候选可审阅 | 已加载、可学、正确或已被接收 |
| 独立候选验证通过 | 指定树和环境中的具名行为通过 | 已并入 integrated 或当前运行实例 |
| 技术 ACCEPT | 指定合同、候选、审查覆盖内接受 | Owner 体验满意、真人学习有效、发布获准 |
| 已接入 / 实例已更新 | 准确整合和目标运行读回成立 | 所有课程或端到端场景都已验收 |
| 产品/体验接受 | 明确范围的教学表达、操作与呈现满足约定 | 长期学习效果或所有人群适用 |
| 真实学习观察 | 具名对象在真实条件下的结果与帮助记录 | 未观察群体的效果、认证等级或市场承诺 |
| 暂停 / 阻塞 / 未触发 | 分别有明确暂停、具名缺口或尚未进入该阶段 | 不把缺证据写成失败，不把计划写成在途 |
