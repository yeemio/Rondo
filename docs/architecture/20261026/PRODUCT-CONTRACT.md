# Rondo · 回旋曲：产品合同 v0.1

日期：2026-10-26。状态：**本阶段设计基线已形成；课程建议与下一阶段实施范围待 Owner 裁定**。本文件落实[交接入口](../../handoff/START-HERE.md)，不改写两份[需求](../../planning/rondo-requirements-20261026.md)与[规划](../../planning/rondo-product-plan-20261026.md)原件。工程边界见 [ARCHITECTURE.md](ARCHITECTURE.md)，实施责任见 [DELIVERY-PLAN.md](DELIVERY-PLAN.md)。

## 1. 目标、责任与本阶段停止条件

Rondo 帮助孩子把预测变成可操作的模型、步骤或程序，再用证据检查、解释和修正；同一概念在陌生情境和延迟回看中再次出现。产品结果不是观看动画、累计题量或收到 AI 回答。

本阶段目标是让下一位实施者能依据明确的领域状态、接口、路径、依赖和验收标准开始工作。当前聊天是 Rondo 本阶段唯一主控与文档 writer；供体项目没有发生控制权转移。本阶段不启动产品实施。

设计停止条件：产品合同、生命周期、数据/权限/API、DSH/工程架构、八课场景合同、复用处置和去重任务图相互一致；首批范围可供批准；已核事实、设计选择和未验边界分开。达到条件后停止扩展架构，不以全量课程、部署或真人结果作为这次文档交付的退出条件。

## 3. 人群、进入条件与学习结果

首个验证对象仍是当前约 11–12 岁六年级孩子和监护人。内容暂按具备基本四则运算、短文阅读和简单数量关系能力的 10–13 岁孩子设计；这不是整个年龄段适用性已获验证。

进入首单元前检查四项：区分半径/直径；理解长方形面积；能做基本乘除；能区分长度单位与面积单位。缺项提供相应的短补充材料，保留起点记录，不按年级自动认定掌握。键盘输入或阅读负担过大时，允许用结构化选择、参数操作和监护人逐字代录解释；代录与概念提示分别记录。

首单元预期结果分开观察：

- 数学与推理：说出对象的条件和数量关系，预测单变量改变，能用新情境检查旧方法。
- 计算思维：把参数对应到变量，追踪顺序与有限重复，发现边界或单位错误。步骤卡完成不等于会写 C++。
- AI 素养：用未见样本检验规则，辨认遗漏信息和个人信息，说明何时需要人的判断。离线实验如实标明数据与算法来源。

## 4. 一张能力图，多个入口

首期能力节点只服务当前学习安排。教材位置和 GESP 条目是带来源/版本的外部映射，不是学习状态，也不是报名资格。

| 节点 | 需要的前置 | 当前可观察证据 | 首单元位置 |
|---|---|---|---|
| K0 测量、单位和基本运算 | 起点诊断 | 能区分长度/面积，读取给定尺寸 | 进入前按缺项补充 |
| K1 对象参数与观察视角 | K0 | 转动视角不改尺寸；改单一参数并预测 | 第 1 课 |
| K2 展开与不变量 | K1、圆周长概念 | 将圆周与展开边对应，在新尺寸上解释 | 第 2 课 |
| K3 面的组合与条件 | K2、圆面积 | 按盖子条件选面，说明遗漏 | 第 3 课 |
| K4 层叠、乘法与重复 | K1、底面积 | 分别解释半径/高度改变对体积的影响 | 第 4 课 |
| K5 适用条件与反例 | K4、比例直觉 | 识别同底等高，拒绝不满足条件的套用 | 第 5 课 |
| K6 量纲与数值表示 | K0、K4 | 在不同单位间转换，识别程序中的截断 | 第 6 课 |
| K7 枚举、约束与模型检验 | K3、K4、K6 | 不重不漏检查有限方案，发现分类器漏掉的变量 | 第 7 课 |
| K8 迁移与说明限制 | K2–K7 对应目标的证据 | 陌生任务中建模、验证、解释，保留提示量 | 第 8 课及延迟回看 |

K5 不作为 K6 的硬前置；第 8 课只对实际学习过的目标发任务，不把所有节点强行串成单链。学习路径允许补充、重试和跳回，不能把观看次数当解锁依据。

完整路线保留规划中的 A–E 阶段：对象变化 → 分类/枚举 → 数据组织与方法 → 策略/代价 → 项目或竞赛分流。分数、百分数、比与比例、数量关系、图形运动、数据与概率都有独立数学路径；首期只登记位置与前置关系，不生产整套题库。GESP 关联始终标记为“部分能力关联”，考级补齐和当年资格核对另立范围。非竞赛孩子可以只用模型和步骤卡完成同一问题。

## 5. 连续八课的内容合同

所有课复用一个播放器和同一尝试/判分/证据协议。每课建议 20–30 分钟、可拆次，这是节奏假设；不以超时判失败。数字、故事、问题与图示采用原创内容。

| 课次 / task family | 核心问题与动作 | 服务端可检查的结果 | 必须保留的解释/迁移证据 | 范围 |
|---|---|---|---|---|
| L1 / `cylinder.parameters.v1` | 哪些参数决定圆筒？独立改半径/高度，切换截面和视角 | 尺寸识别、单变量预测、相机/领域变化分类 | 换视角仍指出半径、直径和高度；新尺寸再判断 | 首批 |
| L2 / `cylinder.net.v1` | 展开后哪条边没有变？展开/卷起，改变尺寸后复验 | 周长边/高度边对应，侧面积数值及单位 | 说明卷回后对应的边；陌生尺寸独立完成 | 首批 |
| L3 / `cylinder.faces.v1` | 有盖/无盖需要一样多材料吗？选择面与组合面积 | 面集合、盖数、面积与单位 | 为新包装说明包括哪些面，修正漏算 | 后续 |
| L4 / `cylinder.layers.v1` | 容量由高还是宽决定？等厚层叠与参数比较 | 层厚×层数、底面积×高、变量变化关系 | 解释高度线性变化与半径变化的不同 | 后续 |
| L5 / `cone.conditions.v1` | 三分之一关系何时可用？配对底面/高度 | 条件匹配、反例选择及数值 | 指出不能套用的例子；预设动画不充当证明 | 后续 |
| L6 / `measure.units.v1` | 长度、面积、体积和容量怎样区分？切换单位 | 量纲、换算和数值类型结果 | 发现量纲错误；区分数学精确值与机器近似 | 后续 |
| L7 / `design.constraints.v1` | 怎样挑选容器？枚举候选、核查约束和离线模型 | 可行集合、枚举覆盖、合成样本分类观察 | 拒绝一个错误方案，说出模型遗漏信息 | 后续 |
| L8 / `transfer.container.v1` | 换一种包装，还会吗？从陌生图构造模型 | 与冻结目标相符的结构化解答 | 首次预测、修正、解释、实际帮助；安排延迟回看 | 后续 |

L2 不固定“周长一定是展开图长边”：当高度超过周长时，周长对应边可能更短。内容与 UI 用“周长对应边”“高度对应边”，并包含高而细的反例；不把某张图的视觉朝向当普遍关系。

首批至少有每课一个引导任务、一个不同参数的独立任务，以及两课合用的陌生情境任务。延迟回看复用任务机制，生成独立题目实例；不能原题原参数重放后标为迁移。首批不要求三维母线旋转成体、圆锥或体积切拼，避免把供体六课的范围带入两课。

## 6. 孩子与监护人的旅程

监护人先在本地控制的服务上建立家庭与学习者，选目标和保存策略，再切换到受限学习者会话。孩子进入后看到“继续上次”或“从这个问题开始”；入口不堆放底层工具、模型配置和课程工程版本。

一次学习经历为：

1. 阅读短问题和已知条件，提交自己的预测。预测不要求先正确。
2. 操作对象并确认关键改变。每帧动画不记为学习事件；已确认状态和本地预览清楚区分。
3. 提交结果，看到来自服务端的有限反馈；需要时选择版本化提示，重试保留原预测与旧答案。
4. 解释为什么改变或保持判断。可以用结构化条件选择加短文；自由文本只保存供人阅读。
5. 回看本次预测、关键修正、帮助与仍待解释的问题。完成流程与达到课的退出标准分别显示。

断线时可继续观察当前对象和编辑本地草稿，但页面明确“尚未保存”；不产生已完成或已判分标签。恢复后先查原命令回执，确认状态后再继续。跨设备只恢复服务端确认内容，本地草稿需原设备取回；共享设备切换学习者前提醒尚未保存的内容。

监护人看到的是一条带上下文的时间线：问题和目标、首次预测、关键改变、最终结果、用了什么帮助、孩子的解释、待观察项和下一次任务。不得只呈现分数/等级。介入记录分为操作帮助、重述题意、概念提示、给出答案；补录介入会修正“独立完成”的证据标签，保留修订历史。

## 7. 学习事实与评价权威

| 事实 | 记录或判断者 | 不能据此推出 |
|---|---|---|
| 操作、提交、服务端收到的顺序 | Rondo 领域服务 | 操作发生就理解了 |
| 数值、单位、构造条件是否符合题目 | 冻结的确定性规则 | 开放解释质量、长期掌握 |
| 解释是否说出条件、关系、依据 | 监护人或后续授权教学审阅人 | 自动模型评分已成立 |
| 接触过 / 提示下完成 / 独立完成的观察 | 对应任务结果与介入证据 | 整个能力永久掌握 |
| 延迟迁移已观察 | 独立迁移实例、实际间隔、结果和帮助记录 | 单孩子证明普遍学习效果 |
| 程序结果 | 真实编译执行回执或明确标识的教学步进 | 有限样例等于数学证明 |

这些是可并存、可补充的证据，不实现一个永不回退的“掌握等级”。考试成绩单独记录；单次通过不覆盖历史错误，人工注释不改写确定性判分原件。

## 8. 必做、延期与非目标

首批必做：一个播放器；两课原创内容；服务端构题/判分；公开与私有内容隔离；学习者/家庭权限；预测、操作、解释、提示记录；回执查回和断线恢复；three.js 与可操作 SVG/DOM 等价路径；监护人读面、数据导出和删除入口；陌生任务与延迟回看机制。

首批采用步骤卡和固定程序示意，标为“步骤演示”；真实 C++ 是否加入须由范围决定。AI 启蒙用人工错误建议、合成数据和确定性实验，不依赖模型联网。后续真实 Tutor 也不能成为答案或学习状态的写入者。

延期：其余六课内容生产；更多几何实验室；完整教材/考级覆盖；第二门语言；真实 Tutor；多人云服务；学校后台；支付/商业定价；Windows/Intel Mac 和独立浏览器发行；语音/照片采集；全量旧题库迁移。旧 151+8 条失败行不转成 Rondo 的 159 个必修缺陷。

## 10. 成本和待决策

沿用参数化估算：制作投入 = 设计 + 内容审阅 + 场景/工程 + 实际返工；家庭运行投入 = 服务分摊 + 存储/备份 + 可选编译计算 + 支持时间 + 可选模型调用。首批外部模型调用计划为零；不把它当总成本为零。

DSH/three.js 和最新 macOS 桌面优先决定不再重复选型。唯一即时决定是是否授权 [DELIVERY-PLAN.md](DELIVERY-PLAN.md) 的两课实施范围（推荐先采用能力先修主线、步骤卡与离线 AI），并给出人员/成本上限。C++/考级意愿与家庭时间可在真实执行或试用前补充，不阻塞本次可逆设计。八课扩展、部署、真人数据、付费、Git 发布及商标/法律事项仍需各自真实边界上的决定。
