# Rondo：场景与两课首批交互合同 v0.1

本文件冻结场景的领域含义和可操作等价入口，不是已经制作的课程。L1/L2 为建议首批，L3–L8 是后续连续单元的设计边界。整体学习流程、角色与回执使用 [LIFECYCLE-DATA-API.md](LIFECYCLE-DATA-API.md)，不在场景里另建学习进度、判分或权限系统。

## 1. 所有 renderer 的共同合同

`SceneDescriptor` 指定 `rendererId/rendererContractVersion/publicStateSchemaVersion/publicAssetHashes/allowedOperations`；Host 核对内容发布中的同一份登记，前端不能自己选择 renderer URL 或版本。组件只加载静态编译入应用的注册项。

一个场景组件接收 `PublicSceneState` 与阶段可见材料，发出 typed 操作或响应草稿；实际确认通过领域命令。相机、焦点、拖动临时值与动画插值保留在 ViewState，不能改变权威状态。即便本地预览使用同一纯计算函数，Host 仍重新校验和计算，不接收客户端给定的正确性/面积/体积作为答案权威。

每个任务有两种表达：`WEBGL2` 与 `SVG_DOM`。three.js 的 `WebGLRenderer` 使用 WebGL 2；WebGL 1 自 r163 起不再支持，因此按能力检测选择入口，不靠浏览器名称推断。[three.js 官方文档](https://threejs.org/docs/pages/WebGLRenderer.html)

初始化失败或运行中 context loss 时，保留最后确认状态、当前草稿和焦点，切换至 SVG/DOM；重新获得 WebGL 时从同一状态重建，不重建 attempt、不清零提示、不重复提交。SVG 不是截图：所有学习关键操作仍有可操作控件，判分接口完全相同。

## 2. 单位、数值与状态

首两课的几何输入以整数毫米存储：`radiusMm ∈ [5,100]`，`heightMm ∈ [10,200]`，步长 1 mm。界面主要显示厘米，一位小数；服务端拒绝 NaN、无穷、负值、越界或未登记单位，不静默截断。教学任务可在此范围内进一步收窄，不得由 renderer 扩大。

首单元数值合同取 `π=3.14=157/50`，明确是本课计算约定，图形仍按真实圆的参数化几何绘制。领域计算用整数/有理数，不按 DOM 显示值中途舍入。要求两位小数的题明确写“四舍五入保留两位小数”，按同一十进制规则生成规范答案；输入允许等价写法如 `8`/`8.00`，不同单位需按任务允许的等价换算核对。容差不能来自 Mesh、像素或泛用浮点 epsilon。

共同公开状态示意：

```ts
type CylinderStateV1 = {
  radiusMm: number;
  heightMm: number;
  unrollPermille: number; // 整数 0..1000；渲染中间帧不落库
  section: 'NONE' | 'TRANSVERSE' | 'AXIAL';
  selectedFaceIds: string[];
};
type CylinderOperationV1 =
  | { type: 'SetDimension'; dimension: 'RADIUS' | 'HEIGHT'; valueMm: number }
  | { type: 'SetUnroll'; valuePermille: number }
  | { type: 'SetSection'; section: CylinderStateV1['section'] }
  | { type: 'SelectFaces'; faceIds: string[] };
```

每课只开放自己的子集；以上不是任意课均可调用的总权限。操作规范化、phase、attemptVersion 与题目 givens 由 Host 再核；提交时保存准确状态快照。探索/观察可显示的公式与测量值也按 `materialVisibility` 投影，独立测评不下发该题的目标答案或 correctIndex。

## 3. L1：哪些参数真正决定圆筒

身份：`taskFamily=cylinder.parameters.v1`，`rendererId=rondo.cylinder`，`rendererContractVersion=1`。对象是直圆柱、半径/直径/高度标记、两个截面；首批不加入圆锥和旋转成体。

| 动作 | 领域状态与前提 | 反馈和学习目的 | 键盘/DOM 入口 | SVG/DOM 等价 |
|---|---|---|---|---|
| 绕对象观察、缩放、复位视角 | 只变 ViewState；radius/height 不变 | 尺寸标签保持，区分“看起来”与“物体改变” | 聚焦场景后方向键旋转、加减缩放、复位按钮；输入框内不劫持按键 | 前/侧/俯视选择按钮和同一尺寸表 |
| 改半径或高度 | `SetDimension`；OPERATE；任务允许该参数 | 本地预览标“未确认”；确认后显示新尺寸，保留旧参数用于比较 | 有标签的数字输入、步进按钮、slider、确认按钮 | 同一输入控制 SVG 轮廓和尺寸表 |
| 看横截面/轴截面 | `SetSection`；合法枚举 | 显示切面与对应几何，关联形状和测量对象 | 三项 radio group；状态文字说明当前截面 | 圆形/矩形示意与尺寸表 |
| 识别参数、预测变化 | 保存为 prediction/response，不直接改模型 | 先保存预测，再给观察；答案由服务端判 | 普通表单/单选与明确提交 | 与 3D 共用同一任务卡 |

引导任务顺序：给 `r=3.0 cm,h=8.0 cm`，先判断旋转观察是否改变尺寸；再只将 `r` 改为 `4.0 cm`，记录对直径变化的预测；比较确认状态并解释。该例是教学材料，不能同时作为首个独立任务的私有答案。

独立任务改用服务端生成的不同尺寸，轮流改变视角和一个参数；要求识别变化与不变项。判分检查参数识别和结构化预测，解释另外人工观察。相机转了几次、停留时长与截图是否好看都不作为完成依据。

完成证据：在另一个视角仍识别半径/直径/高度；能区分观察方式和尺寸变化；有首次预测、至少一次确认操作、提交与解释。只有看到尺寸标签还不能记录“独立识别”，独立任务中的待识别标签要按投影隐藏。

## 4. L2：展开后哪条边没有变

身份：`taskFamily=cylinder.net.v1`，复用 `rondo.cylinder@1`。对象是圆柱侧面、接缝、展开矩形、两组可配对边；不要求底面加入侧面积计算。

| 动作 | 领域状态与前提 | 反馈和学习目的 | 键盘/DOM 入口 | SVG/DOM 等价 |
|---|---|---|---|---|
| 展开/卷起至指定进度 | `SetUnroll`；0..1000；操作阶段 | 对应弧段与已展开边同步，突出长度保持 | 0–100% slider、完全展开/卷起按钮；支持离散步进 | 圆周分段与展开条带联动，不靠动态透视 |
| 改尺寸后再次展开 | `SetDimension`；探索任务允许；独立题 givens 锁定 | 展开形状随参数变化，不把视觉长边固定为周长边 | 参数输入+确认；新的题目用 BeginCycle 重新预测 | 等比例矩形与尺寸表同步 |
| 配对展开边与圆柱对象 | 响应草稿使用稳定对象 ID；服务端核对 | 保存选边与依据；错误反馈不直接暴露全部答案 | 两组 select/radio；避免只能拖线配对 | 相同对象 ID、相同响应表单 |
| 提交侧面积与单位 | 提交当前确认快照对应响应 | 检查数值/单位，显示已批准提示与后续解释问题 | 数字/单位表单、提交按钮 | 相同表单、相同服务端判分 |

不能固定“展开图横边是周长”或“长边是周长”。矩形在画面中的朝向是表达选择；领域关系是一个方向对应底面圆周，另一个对应高。至少一个独立例采用 `r=0.5 cm,h=12.0 cm`，其中周长对应边短于高度边，避免背图形外观。

引导材料可在预测保存后逐步揭示 `C=2πr` 与 `S侧=C×h`。新独立题在答案提交前不下发已计算的目标侧面积；辅助阅读文本和测量卡遵守相同可见性，不能主画面隐藏而 DOM 泄露。所有数值判分由私有规则重新计算。

陌生任务至少改变故事和图的朝向，并更换参数；操作机制保留，避免把操作障碍错当概念不会。孩子要说清卷回后哪条边形成圆周、哪条边成为高。开放解释只留下人工量规观察，不使用文本关键词冒充理解评分。

## 5. 后六课的完整场景边界

这些合同支持后续内容任务直接落地；当前不创建对应 renderer 实现或题目库。使用同一播放器、命令、记录与恢复能力。

| 课 / 对象 | 允许参数与领域操作 | 可见反馈与判分边界 | 键盘等价 | WebGL 失败后的可操作表达 |
|---|---|---|---|---|
| L3 圆柱侧面、顶/底面、包装选择 | 尺寸；盖数 `0/1/2`；`SelectFaces`；任务明确给定还是让孩子构造 | 选择的面高亮、展开后按面列面积；服务端检查面集合及总面积，不能只检查一个总数掩盖漏面 | 面 checkbox、盖数 radio、尺寸输入与确认 | 可点击的展开 SVG 面片与面清单；同样可以取消/增加盖子 |
| L4 圆柱、等厚层和累加步骤 | 尺寸；层数 `1..40`；`SetLayerCount`、`SetVisibleLayerCount`；层厚由总高/层数导出 | 比较高度与半径的影响，显示累计体积；改变层数不改变对象总体积；公式模型动画不冒充实验测量 | 层数输入、逐层/复位按钮、步骤表 | 二维层条、横截面与累计表联动；可逐层操作并提交相同任务 |
| L5 圆柱与圆锥配对 | 各自半径/高度；选择配对；`SetPairDimensions` | 同底等高时模型显示体积三分之一；条件不符时如实变化；动画标为公式模型而非公式证明 | 两组参数输入、同底/等高条件选择、配对按钮 | 两个轮廓图+尺寸/条件表+可选配对；仍可制造条件不符反例 |
| L6 同一容器与多单位标尺 | 规范尺寸不变；显示单位从 `mm/cm/dm`、`cm3/mL/L` 登记表选择；响应带量纲 | 单位切换只改表示，容量不改变；整数除法/近似在步骤活动里如实标识 | 单位 select、数值输入、执行一步/复位 | 二维容器、量纲表和换算步骤；同一响应和判分 |
| L7 有限容器候选与合成数据点 | 冻结的候选尺寸集合、容量/材料约束；选择方案、勾选已检查项；模型版本固定 | 展示可行/不满足的具名条件；分类预测与权威约束结果分列；没有“AI 判学生” | 候选表、排序/比较按钮、样本分类选择、显示反例按钮 | 可操作数据表与二维散点/尺寸图，共用候选集合和模型结果 |
| L8 陌生包装、任务目标与已学操作 | 服务端按已学目标生成；只开放相应登记操作，不能任意 URL/场景脚本 | 首次预测/构造/提交/解释/介入；独立模式默认不展示目标量 | 复用对应课表单与键盘路径，入口和任务措辞变化 | 复用对应 SVG/DOM 表达；未实现的任务不得出现在迁移生成目录 |

L3–L8 的 private rubric 必须与每课目标同一内容任务交付，不能先上场景再临时让模型判答案。L4 暂选等厚层叠；供体“16 楔块切拼成近似长方体”不是必做，也不能把有限切片图说成严格长方体证明。

L7 合成数据分训练展示与未见检验集，版本、生成规则和分类算法固定；孩子可以揭示样本标签作核查，但标签由课程规则产生，不能来自真实家庭。模型预测错与孩子操作错分别记录。L8 初次迁移和延迟迁移使用不同实例，不让先前正确答案原样出现在目标提示中。

## 6. 输入、反馈与可访问性

- 每个学习动作有可读名称、当前值、允许范围、单位和确认方式；选择颜色之外同时使用文字/形状/状态。焦点顺序沿任务卡→操作控件→提交→反馈→解释，不要求精准拖拽。
- 键盘操作与鼠标产生相同 typed intent。方向键只在场景获得焦点时旋转；在输入框/slider 内遵循原生行为。错误后焦点回到需要修正的字段，反馈使用适度 live region，不逐帧播报。
- 拖动期间本地流畅预览；松手或点击确认后发送一条 canonical 操作。取消拖动还原最后确认状态。动画期间快速连续输入只合并本地预览，不能丢掉已经发送的命令身份。
- 降低动态效果时直接切到目标姿态，领域状态与记录相同。窗口缩小采用场景与任务卡上下排列，首批至少在 960×640 与 1280×800 的 macOS 窗口完成流程；不继承试点“移动端截图通过”为产品平台接受。
- 场景卸载/切课释放 GPU 资源、事件监听和动画帧；恢复先加载完整确认状态再创建几何。性能指标只记录当前 Mac 的实际设备和窗口条件，不预写全设备帧率保证。

## 7. 原型资产的处置

可适配：圆柱参数化几何、展开动画思路、双面表达、相机取景、部分 DOM 锚点和二维展开条带。需改成消费公开状态、发 typed intent，资源版本由 Rondo 根锁/manifest 管理。

必须重新实现：前端 `deterministicJudge`、页面中的 correctIndex/expected 常量、localStorage 的课程完成判定、无条件显示目标量、仅“需 WebGL”的降级页。原 PoC 的 iframe/DOM 跨页读写建议不成为产品接口；本项目通过类型化数据与回执恢复。

供体最新报告中的“17 步 ALL PASS”保留其 PoC 作用域。本阶段没有重跑供体验证，也没有证明它的每个场景符合本合同。六课现有状态是复用候选，不阻塞 Rondo 两课设计，也不取消原 writer 的责任。

## 8. 两课验收的最小场景集合

实现稳定后检查：L1 参数变化/相机不变性；L2 正常与高细两种尺寸的边对应；鼠标与纯键盘操作等价；WebGL 初始化失败及操作中 context loss 后仍完成相同任务；确认状态/未保存草稿区别；未知 renderer/版本/动作拒绝；评测阶段 DOM/资源没有目标答案；重启恢复不重复提交；解释和帮助证据可由监护人读回。

主控依据实际 Mac 上的窗口、领域回执和持久记录接受。截图只能说明画面，程序测试只能说明相应行为；真人能否理解与是否喜欢，留给单家庭观察。
